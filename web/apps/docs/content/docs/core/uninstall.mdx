---
title: Uninstall
description: "Learn how to uninstall Astron Collection on your server"
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

Follow these steps to completely remove Astron Collection and its components from your server.

<Steps>
<Step>
Remove the docker swarm services created by Astron Collection:

   ```bash
   docker service remove astron-collection astron-collection-traefik astron-collection-postgres astron-collection-redis
   docker container remove -f astron-collection-traefik
   ```
 
</Step>
 
<Step>
 
Remove the docker volumes created by Astron Collection:

   ```bash
   docker volume remove -f astron-collection astron-collection-postgres astron-collection-redis
   ```
 
</Step>

<Step>
 
Remove the docker network created by Astron Collection:

   ```bash
   docker network remove -f astron-collection-network
   docker network remove -f ingress
   ```
 
</Step>

<Step>

If you were running a Cluster, then for each worker node, remove all it's services and make it leave the swarm:

   ```bash
   docker service rm $(docker service ls -q)
   docker system prune -a -f
   docker swarm leave
   ```
</Step>

<Step>

Make the manager node (where Astron Collection is installed) leave the swarm (run it on all manager nodes if you had more than one):

   ```bash
   docker swarm leave --force
   ```
</Step>

<Step>

Docker cleanup to remove leftovers:

   ```bash
   docker container prune --force
   docker image prune --all --force
   docker volume prune --all --force
   docker builder prune --all --force
   docker system prune --all --volumes --force
   ```
 
</Step>
 
<Step>

Remove the astron-collection files and directories from your server:

   ```bash
   sudo rm -rf /etc/astron-collection
   ```
 
</Step>
</Steps>
