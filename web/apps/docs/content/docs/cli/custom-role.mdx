Organization roles built from a set of permission statements.

`astron-collection custom-role` exposes **6 commands**. They map one-to-one onto the `custom-role.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection custom-role --help` to list these commands in your terminal, or
	`astron-collection custom-role <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection custom-role all`

Calls `GET /api/trpc/customRole.all`.

```bash
astron-collection custom-role all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |

### `astron-collection custom-role create`
