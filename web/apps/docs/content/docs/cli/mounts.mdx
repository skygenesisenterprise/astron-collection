Bind mounts and named volumes attached to applications and Compose services.

`astron-collection mounts` exposes **6 commands**. They map one-to-one onto the `mounts.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection mounts --help` to list these commands in your terminal, or
	`astron-collection mounts <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection mounts all-named-by-application-id`

Calls `GET /api/trpc/mounts.allNamedByApplicationId`.

```bash
astron-collection mounts all-named-by-application-id --applicationId <value> [options]
```

| Option | Type | Required | Allowed values |

| `--applicationId <value>` | string | Yes | — |
