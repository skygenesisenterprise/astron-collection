Inspect Docker Swarm nodes, node workloads and container statistics.

`astron-collection swarm` exposes **5 commands**. They map one-to-one onto the `swarm.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection swarm --help` to list these commands in your terminal, or
	`astron-collection swarm <command> --help` for a single command.
</Callout>

## Commands
