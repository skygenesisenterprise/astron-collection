Tor onion services attached to a Compose stack: create, start, stop and inspect their status.

`astron-collection onion` exposes **9 commands**. They map one-to-one onto the `onion.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection onion --help` to list these commands in your terminal, or
	`astron-collection onion <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection onion create`

Calls `POST /api/trpc/onion.create`.

```bash
astron-collection onion create --name <value> --composeId <value> --serviceName <value> --targetPort <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--name <value>` | string | Yes | — |
| `--composeId <value>` | string | Yes | — |
| `--serviceName <value>` | string | Yes | — |
| `--targetPort <value>` | number | Yes | — |
| `--virtualPort <value>` | number | No | — |
| `--profile <name>` | string | No | — |
