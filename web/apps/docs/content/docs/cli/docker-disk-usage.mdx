Disk usage per Docker object type, and build cache pruning.

`astron-collection docker-disk-usage` exposes **3 commands**. They map one-to-one onto the `docker-disk-usage.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection docker-disk-usage --help` to list these commands in your terminal, or
	`astron-collection docker-disk-usage <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection docker-disk-usage get-build-cache`

Calls `GET /api/trpc/dockerDiskUsage.getBuildCache`.

```bash
astron-collection docker-disk-usage get-build-cache [options]
```

| Option | Type | Required | Allowed values |

| `--serverId <value>` | string | No | — |
