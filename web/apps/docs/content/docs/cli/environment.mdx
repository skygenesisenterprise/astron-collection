Applications and databases live inside an environment, and environments belong to a project.

`astron-collection environment` exposes **7 commands**. They map one-to-one onto the `environment.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection environment --help` to list these commands in your terminal, or
	`astron-collection environment <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection environment by-project-id`

Calls `GET /api/trpc/environment.byProjectId`.

```bash
astron-collection environment by-project-id --projectId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--projectId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
