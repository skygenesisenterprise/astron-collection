Community sources, repositories, releases and the health report of the instance's community presence.

`astron-collection community` exposes **14 commands**. They map one-to-one onto the `community.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection community --help` to list these commands in your terminal, or
	`astron-collection community <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection community activity`

Calls `GET /api/trpc/community.activity`.

```bash
astron-collection community activity [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--preset <value>` | string | No | `24h`, `7d`, `30d`, `90d`, `custom` |
| `--from <value>` | string | No | — |
| `--to <value>` | string | No | — |
| `--repositoryIds <json>` | array | No | — |
| `--types <json>` | array | No | — |
| `--limit <value>` | number | No | — |
| `--offset <value>` | number | No | — |
| `--profile <name>` | string | No | — |
