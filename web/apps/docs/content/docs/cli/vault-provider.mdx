External secret managers connected to the platform to resolve secrets at deploy time.

`astron-collection vault-provider` exposes **13 commands**. They map one-to-one onto the `vault-provider.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection vault-provider --help` to list these commands in your terminal, or
	`astron-collection vault-provider <command> --help` for a single command.
</Callout>

## Commands
