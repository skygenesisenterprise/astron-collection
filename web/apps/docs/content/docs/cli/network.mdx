Docker networks: create, import, inspect and resynchronise them across servers.

`astron-collection network` exposes **10 commands**. They map one-to-one onto the `network.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection network --help` to list these commands in your terminal, or
	`astron-collection network <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection network all`

Calls `GET /api/trpc/network.all`.

```bash
astron-collection network all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--serverId <value>` | string | No | — |
| `--profile <name>` | string | No | — |
