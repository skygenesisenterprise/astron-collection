Attach domains to applications and Compose stacks, and generate or validate them.

`astron-collection domain` exposes **11 commands**. They map one-to-one onto the `domain.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection domain --help` to list these commands in your terminal, or
	`astron-collection domain <command> --help` for a single command.
</Callout>

## Commands
