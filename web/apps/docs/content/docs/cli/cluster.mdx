Add and remove Swarm workers and managers.

`astron-collection cluster` exposes **4 commands**. They map one-to-one onto the `cluster.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection cluster --help` to list these commands in your terminal, or
	`astron-collection cluster <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection cluster add-manager`

Calls `GET /api/trpc/cluster.addManager`.

```bash
astron-collection cluster add-manager [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--serverId <value>` | string | No | — |
| `--profile <name>` | string | No | — |
