Publish container ports directly, without routing them through a domain.

`astron-collection port` exposes **4 commands**. They map one-to-one onto the `port.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection port --help` to list these commands in your terminal, or
	`astron-collection port <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection port create`

Calls `POST /api/trpc/port.create`.

```bash
astron-collection port create --publishedPort <value> --publishMode <value> --targetPort <value> --protocol <value> --applicationId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--publishedPort <value>` | number | Yes | — |
| `--publishMode <value>` | string | Yes | `ingress`, `host` |
| `--targetPort <value>` | number | Yes | — |
| `--protocol <value>` | string | Yes | `tcp`, `udp` |
| `--applicationId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
