Roll a deployment back to a previously built image.

`astron-collection rollback` exposes **2 commands**. They map one-to-one onto the `rollback.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection rollback --help` to list these commands in your terminal, or
	`astron-collection rollback <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection rollback delete`

Calls `POST /api/trpc/rollback.delete`.

```bash
astron-collection rollback delete --rollbackId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--rollbackId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |

astron-collection rollback rollback --rollbackId <value> [options]
