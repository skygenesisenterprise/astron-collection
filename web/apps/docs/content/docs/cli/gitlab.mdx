GitLab connections, plus branch and repository lookups.

`astron-collection gitlab` exposes **7 commands**. They map one-to-one onto the `gitlab.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection gitlab --help` to list these commands in your terminal, or
	`astron-collection gitlab <command> --help` for a single command.
</Callout>
