Custom TLS certificates loaded by Traefik alongside automatic Let's Encrypt ones.

`astron-collection certificates` exposes **8 commands**. They map one-to-one onto the `certificates.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection certificates --help` to list these commands in your terminal, or
	`astron-collection certificates <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection certificates all`

Calls `GET /api/trpc/certificates.all`.

```bash
astron-collection certificates all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |
