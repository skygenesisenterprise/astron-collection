HTTP redirects served by Traefik for an application's domains.

`astron-collection redirects` exposes **4 commands**. They map one-to-one onto the `redirects.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection redirects --help` to list these commands in your terminal, or
	`astron-collection redirects <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection redirects create`

Calls `POST /api/trpc/redirects.create`.

```bash
astron-collection redirects create --regex <value> --replacement <value> --permanent --applicationId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--regex <value>` | string | Yes | — |
| `--replacement <value>` | string | Yes | — |
| `--permanent [boolean]` | boolean | Yes | — |
| `--applicationId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
