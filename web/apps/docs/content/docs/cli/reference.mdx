## Naming

Groups are the first argument and commands the second: `astron-collection <group> <command>`. Both are
lowercase and hyphenated, matching the API namespace they call (`docker-disk-usage` →
`dockerDiskUsage.*`).

Flags are the input fields of that operation, in camelCase: `--environmentId` is passed
through as `environmentId`. A flag marked **Yes** in the Required column aborts the command
when it is missing, so it always has to be provided; the others are omitted from the request when you
leave them out, which lets the server apply its defaults.

Flag names, required flags and allowed values are read from the CLI itself, so this page cannot drift
from what `astron-collection --help` reports.
