GitHub app connections, plus branch and repository lookups.

`astron-collection github` exposes **6 commands**. They map one-to-one onto the `github.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection github --help` to list these commands in your terminal, or
	`astron-collection github <command> --help` for a single command.
</Callout>

## Commands
