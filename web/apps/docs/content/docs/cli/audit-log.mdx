Every recorded action performed in the organization.

`astron-collection audit-log` exposes **1 command**. They map one-to-one onto the `audit-log.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection audit-log --help` to list these commands in your terminal, or
	`astron-collection audit-log <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection audit-log all`

Calls `GET /api/trpc/auditLog.all`.

```bash
astron-collection audit-log all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--search <value>` | string | No | — |
| `--userId <value>` | string | No | — |
| `--userEmail <value>` | string | No | — |
| `--resourceName <value>` | string | No | — |
| `--action <value>` | string | No | `create`, `update`, `delete`, `read`, `deploy`, `cancel`, `redeploy`, `login`, `logout`, `restore`, `run`, `start`, `stop`, `reload`, `rebuild`, `move` |
| `--resourceType <value>` | string | No | `project`, `service`, `environment`, `deployment`, `user`, `customRole`, `domain`, `certificate`, `registry`, `server`, `sshKey`, `gitProvider`, `destination`, `notification`, `settings`, `session`, `port`, `redirect`, `security`, `schedule`, `backup`, `volumeBackup`, `docker`, `swarm`, `previewDeployment`, `organization`, `cluster`, `mount`, `application`, `compose`, `network`, `vaultProvider`, `dnsProvider`, `objectStorage` |
| `--from <value>` | string | No | — |
| `--to <value>` | string | No | — |
| `--sortOrder <value>` | string | No | `asc`, `desc` |
| `--limit <value>` | number | No | — |
| `--offset <value>` | number | No | — |
| `--profile <name>` | string | No | — |
