Deploy an authentication proxy in front of applications and manage its domains.

`astron-collection forward-auth` exposes **10 commands**. They map one-to-one onto the `forward-auth.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection forward-auth --help` to list these commands in your terminal, or
	`astron-collection forward-auth <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection forward-auth deploy-on-server`

Calls `POST /api/trpc/forwardAuth.deployOnServer`.

```bash
astron-collection forward-auth deploy-on-server --serverId <value> --providerId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--serverId <value>` | string | Yes | — |
