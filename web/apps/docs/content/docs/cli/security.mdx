Per-application HTTP basic auth and response security headers.

`astron-collection security` exposes **4 commands**. They map one-to-one onto the `security.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection security --help` to list these commands in your terminal, or
	`astron-collection security <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection security create`

Calls `POST /api/trpc/security.create`.

```bash
astron-collection security create --applicationId <value> --username <value> --password <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--applicationId <value>` | string | Yes | — |
| `--username <value>` | string | Yes | — |
| `--password <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
