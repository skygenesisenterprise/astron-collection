List, share and remove every Git provider connected to an organization.

`astron-collection git-provider` exposes **4 commands**. They map one-to-one onto the `git-provider.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection git-provider --help` to list these commands in your terminal, or
	`astron-collection git-provider <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection git-provider all-for-permissions`

Calls `GET /api/trpc/gitProvider.allForPermissions`.

```bash
astron-collection git-provider all-for-permissions [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |

### `astron-collection git-provider get-all`

Calls `GET /api/trpc/gitProvider.getAll`.

```bash
astron-collection git-provider get-all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |

### `astron-collection git-provider remove`

Calls `POST /api/trpc/gitProvider.remove`.

```bash
astron-collection git-provider remove --gitProviderId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--gitProviderId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |

### `astron-collection git-provider toggle-share`

Calls `POST /api/trpc/gitProvider.toggleShare`.

```bash
astron-collection git-provider toggle-share --gitProviderId <value> --sharedWithOrganization [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--gitProviderId <value>` | string | Yes | — |
| `--sharedWithOrganization [boolean]` | boolean | Yes | — |
| `--profile <name>` | string | No | — |
