Create, update, search and remove projects, and read the onboarding state of an instance.

`astron-collection project` exposes **11 commands**. They map one-to-one onto the `project.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection project --help` to list these commands in your terminal, or
	`astron-collection project <command> --help` for a single command.
</Callout>

## Commands
