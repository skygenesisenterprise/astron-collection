Publish incidents and maintenance windows to the public status page.

`astron-collection status` exposes **12 commands**. They map one-to-one onto the `status.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection status --help` to list these commands in your terminal, or
	`astron-collection status <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection status add-incident-update`

```bash

```
