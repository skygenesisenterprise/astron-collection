Versioned file overrides applied to an application at deploy time.

`astron-collection patch` exposes **12 commands**. They map one-to-one onto the `patch.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `astron-collection patch --help` to list these commands in your terminal, or
	`astron-collection patch <command> --help` for a single command.
</Callout>

## Commands

### `astron-collection patch by-entity-id`

Calls `GET /api/trpc/patch.byEntityId`.

```bash
astron-collection patch by-entity-id --id <value> --type <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--id <value>` | string | Yes | — |
| `--type <value>` | string | Yes | `application`, `compose` |
| `--profile <name>` | string | No | — |
