## SVG Generation

  <p>
    Use <code>generateCompanyLogoSvg()</code> to get copy-paste ready SVG markup for non-React contexts.
  </p>

```tsx
import { generateCompanyLogoSvg } from "@astron-collection/react";

// Generate glyph SVG (cloud only)
const glyphSvg = generateCompanyLogoSvg({ variant: "glyph" });

// Generate full logo SVG
const fullSvg = generateCompanyLogoSvg({ variant: "full" });

// Generate black logo
const blackSvg = generateCompanyLogoSvg({ color: "black" });

// Copy to clipboard
await navigator.clipboard.writeText(
  generateCompanyLogoSvg({ variant: "glyph", color: "color" }),
);
```
